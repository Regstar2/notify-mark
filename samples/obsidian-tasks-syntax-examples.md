# Примеры синтаксиса Obsidian Tasks (для теста NotifyMark)

Файл для ручной проверки парсинга и уведомлений. В **Настройки → Формат задач** включите режим **«Авто / смешанный»** или **«Obsidian Tasks»**, иначе emoji-метаданные не будут участвовать в напоминаниях.

> Полный плагин Obsidian Tasks (запросы ` ```tasks `, фильтры, сортировки) **не** поддерживаются — только разметка **строки задачи** после чекбокса.

---

## Чекбоксы

- [ ] Активная `- [ ]`
* [ ] Активная `* [ ]`
+ [ ] Активная `+ [ ]`
1. [ ] Активная нумерованный список `1. [ ]`
- [x] Выполнена строчная x
- [X] Выполнена заглавная X
- [-] Отменена / пропущена
- [?] Произвольный статус (сохраняется, может дать предупреждение парсера)

---

## Даты (ISO `YYYY-MM-DD`)

- [ ] Создана ➕ 2026-01-10
- [ ] Старт 🛫 2026-02-01
- [ ] Запланирована ⏳ 2026-03-15
- [ ] Дедлайн 📅 2026-05-20
- [x] Уже сделано ✅ 2026-04-01
- [-] Отменено ❌ 2026-04-02

---

## Напоминание ⏰ и дедлайн 📅

Точное время уведомления:

- [ ] Только часы ⏰ 2026-05-20 14:30

Дата напоминания + время по умолчанию из настроек формата:

- [ ] ⏰ 2026-05-21

Дедлайн без ⏰ → напоминание в день дедлайна в **дефолтное время** (настройка):

- [ ] Только дедлайн 📅 2026-05-22

⏰ время + 📅 дата (время привязывается к дате дедлайна):

- [ ] Сводка ⏰ 09:00 📅 2026-05-23

⏰ и 📅 на разных датах (⏰ выигрывает для момента уведомления):

- [ ] Встреча ⏰ 2026-05-10 12:00 📅 2026-05-11

---

## Повтор 🔁 (подмножество, как в NotifyMark v0.10.x)

Поддерживается маппинг на внутренний repeat (без «тихой» подмены неизвестного на `every day`):

- [ ] Каждый день 🔁 every day 📅 2026-05-13
- [ ] Каждую неделю 🔁 every week 📅 2026-05-13
- [ ] Каждый месяц 🔁 every month 📅 2026-05-13
- [ ] Каждые 2 дня 🔁 every 2 days 📅 2026-05-13
- [ ] Каждые 3 недели 🔁 every 3 weeks 📅 2026-05-13
- [ ] Будни 🔁 every weekday 📅 2026-05-13
- [ ] Понедельник 🔁 every week on Monday 📅 2026-05-13
- [ ] Вторник 🔁 every week on Tuesday 📅 2026-05-13
- [ ] После выполнения (день) 🔁 every day when done 📅 2026-05-13
- [ ] После выполнения (неделя) 🔁 every week when done 📅 2026-05-13

Ожидаемо **без маппинга на расписание** (сырой текст + предупреждение, не подменять на день/неделю):

- [ ] Год 🔁 every year 📅 2026-05-13
- [ ] Сложное NL 🔁 every 2 months on the last Friday 📅 2026-05-13

## Смешение с native NotifyMark (конфликт напоминания — native выигрывает)

- [ ] Смесь @due(2026-05-12 11:00) 📅 2026-05-13 ⏰ 2026-05-13 09:00

## Некорректные даты (парсер не должен падать)

- [ ] Битая дата 📅 2026-13-40
- [ ] Битое время ⏰ 2026-05-13 25:99

---

## Неизвестный emoji в тексте (не удалять)

- [ ] Задача с кастомным 🚀 и напоминанием ⏰ 2026-05-13 10:00

---

## Блок кода (строки внутри обычно не задачи парсера)

```markdown
- [ ] Эта строка внутри fenced block — для справки, не список задач приложения
```

Ниже — то, что **не** парсится как встроенный блок плагина (в NotifyMark не реализовано):

```tasks
not done
```
