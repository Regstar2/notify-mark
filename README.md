# ObsidianNotification

Android-приложение для напоминаний поверх markdown-задач из Obsidian. Прототип v0.1.0 умеет выбрать одну заметку через Storage Access Framework, прочитать ее, найти активные чекбоксы и показать список задач в приложении.

## Синтаксис v0.1.0

Активной считается строка markdown-задачи:

```markdown
- [ ] Позвонить врачу @2026-04-20 14:30 every 15m
- [ ] Проверить Syncthing @20.04.2026 19:00 каждые 10м
- [ ] Быстрая задача @09:30 repeat 1h
- [x] Выполненная задача не попадет в список
```

Поддерживается:

- `- [ ]`, `* [ ]` или `+ [ ]` для активных задач.
- Время напоминания: `@2026-04-20 14:30`, `@2026-04-20T14:30`, `@20.04.2026 14:30` или `@14:30`.
- Повтор: `every 15m`, `repeat 1h`, `каждые 10м`, `повтор 1ч`.

## Сборка

```powershell
.\gradlew.bat assembleDebug
```

APK после сборки:

```text
app/build/outputs/apk/debug/app-debug.apk
```
