# ObsidianNotification

Android-приложение для локальных напоминаний из markdown-заметок Obsidian.

Приложение читает одну заметку, несколько markdown-файлов или папку vault, находит строки с `@due(...)`, планирует локальные Android-уведомления и прекращает повторы, когда задача отмечена выполненной.

## Что умеет v1.0.0

- Читать задачи из markdown-файлов через Storage Access Framework.
- Работать с одним файлом, несколькими файлами или папкой.
- Поддерживать чекбокс-задачи и строки без чекбокса.
- Планировать локальные уведомления без облачных сервисов.
- Повторять уведомления через `@repeat(...)` или до выполнения через `@repeatUntilDone(...)`.
- Выполнять, откладывать, редактировать и удалять задачи из приложения.
- Выполнять и откладывать задачи из уведомления.
- Редактировать одну задачу через UI или открыть весь markdown-файл.
- Восстанавливать напоминания после перезагрузки, обновления приложения, смены времени и часового пояса.
- Сохранять локальный кэш задач на случай временно недоступного файла.

## Быстрый старт

1. Установите APK на телефон.
2. Откройте приложение и пройдите onboarding.
3. Выберите markdown-файл или папку с заметками Obsidian.
4. Разрешите уведомления.
5. Для более точных напоминаний разрешите exact alarms, если Android попросит это отдельно.
6. Добавьте в заметку задачу:

```markdown
- [ ] Купить лекарство @due(2026-04-20 19:00) @repeatUntilDone(15m) @group(health)
```

## Синтаксис задач

Основной формат:

```markdown
- [ ] Купить лекарство @due(2026-04-20 19:00) @repeat(15m)
- [ ] Проверить ответ @due(19:00) @repeatUntilDone(15m)
- [ ] Позвонить врачу @due(2026-04-20)
Plain reminder @due(2026-04-20 19:00) @group(home)
```

Поддерживается:

- `@due(2026-04-20 19:00)`
- `@due(2026-04-20T19:00)`
- `@due(20.04.2026 19:00)`
- `@due(2026-04-20)` с временем по умолчанию `09:00`
- `@due(19:00)` с текущей датой
- `@repeat(15m)`, `@repeat(2h)`, `@repeat(1d)`
- `@repeatUntilDone(15m)`
- `@tag(work health)` и обычные Obsidian-теги `#work`
- `@priority(low)`, `@priority(medium)`, `@priority(high)`, `@priority(urgent)`
- `@group(home)`

Legacy-форматы вроде `@2026-04-20 14:30 every 15m` пока остаются рабочими.

## Поведение повторов

`@repeat(15m)` повторяет уведомление каждые 15 минут. Повтор остановится после следующего чтения заметки, если задача стала завершенной или была удалена.

`@repeatUntilDone(15m)` перед каждым повтором перечитывает источник. Если задача уже отмечена `- [x]`, удалена или изменилась так, что больше не считается активной, повтор останавливается.

Если файл временно недоступен во время проверки, приложение не отменяет существующие напоминания сразу и использует локальный кэш.

## Syncthing

Рекомендуемый сценарий:

1. Синхронизируйте vault или отдельную папку задач через Syncthing на телефон.
2. В ObsidianNotification выберите локальную папку или конкретные markdown-файлы из этой синхронизированной директории.
3. Убедитесь, что приложение получило write-доступ, если хотите выполнять задачи из уведомлений или редактировать markdown из приложения.
4. После изменения заметки на ПК дождитесь завершения синхронизации и нажмите обновление в меню приложения либо дождитесь фоновой проверки.

Приложение защищается от кратковременно пустых или частично синхронизированных файлов: при подозрительном чтении оно сохраняет текущие уведомления и использует кэш.

## Редактирование

Есть два разных сценария:

- UI-редактор задачи: форма одной задачи с preview итоговой markdown-строки.
- Markdown-редактор файла: полный исходный markdown-файл с переходом к строке выбранной задачи.

В настройках можно выбрать основной способ открытия задачи из списка.

## Сборка

Debug APK:

```powershell
.\gradlew.bat assembleDebug
```

Release APK без подписи:

```powershell
.\gradlew.bat assembleRelease
```

Артефакты:

```text
app/build/outputs/apk/debug/app-debug.apk
app/build/outputs/apk/release/app-release-unsigned.apk
```

Для публикации release APK нужно подписать своим keystore.

## Проверки перед релизом

Минимальный набор:

- `.\gradlew.bat testDebugUnitTest`
- `.\gradlew.bat lintDebug`
- `.\gradlew.bat assembleDebug`
- `.\gradlew.bat assembleRelease`
- установка APK на реальное устройство
- выбор файла через SAF
- выбор папки Syncthing через SAF
- проверка `@repeat(...)`
- проверка `@repeatUntilDone(...)`
- выполнение из уведомления
- отложить из уведомления
- редактирование через UI
- редактирование полного markdown-файла
- перезагрузка телефона и проверка восстановления напоминаний

## Обратная связь

Для первых пользователей важнее всего проверить:

- не пропадают ли напоминания после Syncthing-синхронизации;
- не появляются ли дубли уведомлений;
- хватает ли текущего синтаксиса задач;
- удобно ли редактировать задачи из приложения;
- корректно ли работает exact alarm на конкретной версии Android.
