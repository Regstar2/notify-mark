# v0.10.1 — Repeat card display compacting

Patch release focused on task **card** repeat rows: shorter Russian copy, no duplicate repeat emoji in text, and a single-line meta row.

## Repeat card display

- Task list cards use `TaskRepeatDisplayFormatter.formatShortCardLine(ObsidianTask)` for the repeat row (combined repeat schedule and `@repeatUntilDone` when present).
- **Short summary** examples: `ежедневно`, `каждые 12 ч`, `еженедельно · пн, ср, пт`, `до выполнения 5 мин.`, `ежедневно · до выполнения 2 мин.`
- **Full / diagnostic** primary repeat text remains available as `formatFullPrimaryRepeat` / legacy `formatPrimaryRepeat` (warning prefix plus raw Obsidian recurrence where applicable). Raw recurrence continues to live in `TaskLineMetadata` for write-back.
- The **🔁 character is not** prepended to card repeat text; the row already shows the repeat icon (`ic_repeat`).
- **Unsupported** Obsidian recurrence (no executable `RepeatRule`): cards show the fixed short phrase **«повтор не поддержан»**; full text still includes the raw English phrase after the warning prefix.
- **When done** Obsidian recurrence (completion-based, not executed as an ordinary repeat): cards show **«после выполнения не поддержан»**; full text explains with raw phrase. Parser/scheduler behavior is unchanged from v0.10.0.
- Card meta `TextView` uses `maxLines=1` and `ellipsize=end` (with `singleLine`) so a long line truncates instead of growing the card; the main mitigation is shorter copy, not ellipsis alone.

## Compatibility

- Native `@repeat(...)` / `@days(...)` / `@repeatUntilDone(...)` parsing, scheduling, and markdown write-back are unchanged; only display strings and the card repeat row layout behavior changed.

## Tests

- `TaskRepeatDisplayFormatterTest` covers short intervals, weekdays/weekends, weekly day lists, until-done phrases, Obsidian mapped lines, when-done / unsupported short vs full, and native `12h` + `repeatUntilDone` card lines.
