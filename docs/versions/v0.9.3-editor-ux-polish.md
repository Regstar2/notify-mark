# NotifyMark v0.9.3 — Editor UX Polish

## Goal

Make the task editor easier to use (group suggestions, softer placeholders, clearer helpers and validation) without changing markdown syntax, parser semantics, or repeat/notification architecture.

## Fixed issues

- Group field required users to remember exact names from markdown.
- Placeholders and examples shared the same visual weight as real input.
- Validation feedback leaned on generic parser messages for simple input mistakes.

## New behavior

- **Group suggestions:** autocomplete suggestions from the current cached parsed task list (same groups as in the app snapshot), case-insensitive dedupe, stable sort.
- **Hints:** editor field hints use a dedicated tertiary text color so they read softer than body text.
- **Helper lines:** short explanations under key fields (due, repeat, repeat-until-done, grace, snooze, group, priority, tags).
- **Field validation:** due, repeat, repeat-until-done, grace, and snooze tokens are checked with the same rules as the parser before showing the full-document parse errors.

## Group suggestions

- Source: `TaskCache.loadActiveTasks` → `TaskGroupSuggestionProvider.distinctSortedGroups` (includes nested subtasks on parents).
- UI: `AutoCompleteTextView`, threshold 1, standard dropdown.
- Empty group remains valid; default bucket label `ObsidianTask.DEFAULT_GROUP` is not suggested.
- **Subtask editor** does not include a group field (unchanged); suggestions apply to the main task editor only.

## Input examples and helper text

- Central color: `text_tertiary` (light/dark) for hints and helper paragraphs; `text_primary` / `error_text` unchanged for input and errors.
- Repeat block adds `edit_repeat_helper` under the repeat editor controls.
- Field-level helpers live in `strings_task_editor.xml` (Russian, consistent with the rest of the editor).

## Validation behavior

- `TaskEditorInputValidator` runs first; messages from `task_edit_validation_*` strings.
- Optional fields: empty group, priority, tags, snooze, grace when disabled, repeat when cleared — still allowed as before.
- Full `TaskParser.parseDocument` validation remains the gate for save.

## Known limitations

- Group suggestions use the **task cache** from the last main sync; cold edge cases may show an empty list until tasks are loaded.
- **Subtask sheet** has no group field; no group autocomplete there.
- Many legacy editor strings remain inline elsewhere (existing technical debt); this version only adds new resource strings for new UX text.
- **UI/instrumentation tests** were not run; **dark theme** on a physical device was not verified in this session.
