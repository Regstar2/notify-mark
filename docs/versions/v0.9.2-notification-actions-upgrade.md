# NotifyMark v0.9.2 — Notification Actions Upgrade

## Goal

Improve notification UX: reliable small/action icons (including wearables), add “remind at a specific time”, and keep all flows on `NoteStore` / `ReminderScheduler` without duplicating repeat logic.

## Fixed issues

- Small notification icon used the older `ic_notification` asset; task reminders now use a simplified monochrome `ic_stat_notify` drawable.
- Snooze used the generic “repeat” arrow icon; it now uses a clock. Skip uses the dedicated skip icon. “Open” was only via tapping the notification body; an explicit **Открыть** action was added.
- There was no way to snooze until a chosen date/time from the shade.

## New behavior

- **Напомнить…** opens `ReminderTimePickerActivity` with presets: 15 min, 1 h, today 19:00 (rolls forward if already past), tomorrow 09:00, and a system date+time picker.
- Times in the past are bumped to **now + 1 minute** via `ReminderScheduler.ensureFutureTriggerAt` before scheduling.
- After scheduling, the current notification is cancelled (same as quick snooze). Snooze counter increments when preferences request it.
- **Открыть** runs the existing `OPEN_NOTE` flow and dismisses the notification.

## Notification icon changes

- `setSmallIcon(R.drawable.ic_stat_notify)` in `ReminderReceiver` and `TestNotificationSender`.
- Action icons: done (`ic_done_notification`), snooze (`ic_clock`), remind-at (`ic_calendar`), skip (`ic_skip`), open (`ic_open_note_notification`).

## Remind-at-time action

- Implemented as `ReminderTimePickerActivity` (dialog theme, `excludeFromRecents`).
- Uses `ReminderScheduler.scheduleSnoozeUntil(...)` — same alarm pipeline as relative `scheduleSnooze`, with an absolute `LocalDateTime` trigger.
- No new public markdown syntax in this version.

## Known limitations

- Wear OS / physical watch pairing was **not** verified in CI; icon changes follow Android monochrome notification rules, but companion rendering can still vary by OEM.
- “Remind at” uses the same snooze alarm channel as relative snooze; it does **not** add a new `@snoozedUntil(...)` markdown marker.
- Exact alarm restrictions on Android 12+ still follow existing app behavior; no new permission wizard in this version.
