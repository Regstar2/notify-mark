# NotifyMark v0.9.2 — Notification Actions Upgrade

## Goal

Improve notification UX: reliable small/action icons (including wearables), add “remind at a specific time”, and keep all flows on `NoteStore` / `ReminderScheduler` without duplicating repeat logic.

## Fixed issues

- Small notification icon used the older `ic_notification` asset; task reminders now use a simplified monochrome `ic_stat_notify` drawable.
- Snooze uses a clock icon; skip uses the dedicated skip icon. Opening the note is via tapping the notification body (`MainActivity`), not a separate shade action.
- There was no way to snooze until a chosen date/time from the shade.

## New behavior

- **Время** opens `ReminderTimePickerActivity` (dialog-themed, not `MainActivity`): choose **Выбрать время** (time picker only; date is today if the time is still ahead, otherwise tomorrow) or **Выбрать дату и время** (date picker, then time picker). Choosing a date+time in the past shows a toast and re-opens the time step; there is no silent bump to “now + 1 minute” on that path.
- The **+Nм / +Nч / +Nд** snooze action uses the task snooze duration or default preferences, same scheduling pipeline as before.
- After scheduling, the current notification is cancelled (same as quick snooze). Snooze counter increments when preferences request it.
## Notification icon changes

- `ReminderScheduler.applyReminderNotificationIcon` uses `setSmallIcon(R.drawable.ic_stat_notify)` for `ReminderReceiver` and `TestNotificationSender`.
- Action icons: done (`ic_done_notification`), snooze (`ic_clock`), remind-at (`ic_calendar`), skip (`ic_skip`).

## Remind-at-time action

- Implemented as `ReminderTimePickerActivity` (`Theme.Material3.DayNight.Dialog`, translucent window, `excludeFromRecents`, `noHistory`).
- Uses `ReminderScheduler.scheduleSnoozeUntil(...)` — same alarm pipeline as relative `scheduleSnooze`, with an absolute `LocalDateTime` trigger.
- No new public markdown syntax in this version.

## Known limitations

- **Realme Watch S2 icon result:** Realme Link shows NotifyMark icon correctly in the app list; phone notifications show the correct icon; Realme Watch S2 still displays the Android placeholder. This strongly suggests the issue is in the Realme Link / Watch S2 notification bridge or watch-side renderer, not in NotifyMark’s notification builder. Realme Watch S2 is not a Wear OS device and does not necessarily render Android notification icons as provided by the platform. NotifyMark cannot force Realme Watch S2 to use notification `smallIcon` / `largeIcon` via standard Android APIs.
- **Visible action count:** Collapsed notifications may hide the last actions; order is **✓**, **+snooze**, **Время**, **✗** (four actions). Expand the shade if an action is missing.
- **Shell / manufacturer UI** may reorder, iconify, or hide actions regardless of labels.
- **Gradle / manual tests** in this session: see the Cursor result report below for what was actually run.

## Follow-up fixes

Follow-up work tightens shade labels, simplifies the remind-at chooser, fixes dialog theming, and re-audits the notification icon path.

### Notification action labels

- Done / skip use compact **✓** / **✗** labels in the shade (icons remain `ic_done_notification` / `ic_skip`).
- Snooze label is a compact token from the resolved duration, e.g. **+30м**, **+2ч**, **+1д** (Cyrillic suffixes).
- Remind-at action label is **Время** (replaces long “Напомнить…”).
- Separate **open file** shade action was removed; open note remains via notification body tap where supported.

### Remind-at-time picker UX

- Presets (15 min, 1 h, fixed evening/morning) were removed from this menu; quick relative snooze remains on the **+Nм** notification action.
- Two entries only: **Выбрать время** and **Выбрать дату и время**, with the date+time path rejecting past datetimes with a toast instead of silently adjusting.

### Theme compatibility

- `ReminderTimePickerTheme` is `Theme.Material3.DayNight.Dialog` with a translucent window; chooser uses `MaterialAlertDialogBuilder` so surfaces track day/night instead of a forced light Material3 dialog shell.

### Wear OS icon follow-up

- Reminders use `NotificationCompat` with `setSmallIcon(R.drawable.ic_stat_notify)`. Some bridges/devices may still substitute icons by policy; confirm on your hardware.
