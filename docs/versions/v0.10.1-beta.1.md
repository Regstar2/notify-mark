# NotifyMark v0.10.1-beta.1 — Public beta baseline

## Status

This document defines the source/version baseline and release gates for the first public beta.

- Planned Git tag: `v0.10.1-beta.1`.
- Android `versionName`: `0.10.1-beta.1`.
- Android `versionCode`: `26`.
- `applicationId` and namespace remain `com.regstar.obsidiannotification`; this beta does not change Android application identity.
- Full public release notes: [Russian](../releases/v0.10.1-beta.1.md) · [English](../releases/v0.10.1-beta.1_EN.md).

The About screen reads `PackageInfo.versionName`, so it shows `0.10.1-beta.1`. The main drawer footer prefixes the same package version with `v`, so it shows `v0.10.1-beta.1`.

## Short changelog

### Added

- Partial Obsidian Tasks compatibility from v0.10.0: supported emoji metadata can be parsed and preserved on write-back, with compatibility modes and documented recurrence limitations.
- Signed release automation, security audit, SHA-256 artifact generation, and prepared public release notes.

### Changed

- Repeat metadata on task cards is shorter and constrained to a compact single-line row.
- Long task titles are easier to edit and inspect without changing the one-task-per-Markdown-line model.
- Editor handling around tags, block ids, parse warnings, and partial Obsidian due/reminder authoring was tightened as documented in the v0.10.1 notes.
