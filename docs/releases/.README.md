# Releases

Публичные release notes NotifyMark.

Для каждой опубликованной версии поддерживаются две синхронные версии:

```text
vX.Y.Z.md       — русский, основной
vX.Y.Z_EN.md    — English
```

Для prerelease в имени файла сохраняется полный tag, например `v0.10.1-beta.1.md`.

Текущий подготовленный релиз:

- [v0.10.1-beta.1 — русский](v0.10.1-beta.1.md)
- [v0.10.1-beta.1 — English](v0.10.1-beta.1_EN.md)
