## О релизе

- **Версия:** `v0.10.1-beta.1`
- **Канал:** beta
- **Дата подготовки notes:** 2026-10-01
- **Предыдущая публичная версия:** отсутствует; это первый публичный beta-релиз
- **Android:** 8.0+ (`minSdk 26`)
- **applicationId:** `com.regstar.obsidiannotification`

Этот релиз предназначен для публичного beta-тестирования основного сценария: подключить Markdown, увидеть задачи, получить локальное напоминание и записать изменение обратно в Markdown.

> [!WARNING]
> Это предварительная версия. Она не заявляется как стабильная и не должна быть единственной копией важных заметок. Перед подключением рабочих Markdown-файлов сделайте резервную копию или используйте синхронизацию с историей версий.

## Главное

- **Локальные Markdown-напоминания** — задачи остаются в Markdown, а Android-уведомления планируются на устройстве.
- **Несколько типов источников** — встроенное хранилище, отдельные файлы и папки через SAF.
- **Частичная совместимость с Obsidian Tasks** — поддерживаются основные emoji metadata, но не вся грамматика плагина.
- **Подписанный release APK** — публикация блокируется при провале CI, security audit, проверки подписи или checksum.
- **Feedback через GitHub Issues** — подготовлены отдельные формы для ошибок и предложений.

## Изменения

### Добавлено

- список задач и календарь;
- локальные уведомления с действиями выполнить, отложить, пропустить и открыть;
- повторения, `@repeatUntilDone(...)`, grace period, snooze, группы, теги и приоритеты;
- Quick Settings tiles;
- подключение отдельных файлов и папок через SAF;
- частичная поддержка Obsidian Tasks metadata: `📅`, `⏰`, `🔁`, `✅`, `❌`, priority emoji, `🆔` и `⛔`;
- автоматизированная сборка подписанного APK и SHA-256 checksum.

### Изменено

- repeat metadata на карточках показывается компактнее;
- длинные заголовки удобнее редактировать и просматривать;
- обработка tags, block ids, parse warnings и частичного Obsidian due/reminder authoring уточнена.

### Безопасность

- release workflow повторно запускает проектный CI на точном release source;
- APK проходит security audit и `apksigner verify`;
- release-keystore материализуется только во временном каталоге self-hosted runner;
- приложение не запрашивает `INTERNET`.

## Установка и обновление

### Новая установка

1. Откройте [GitHub Release v0.10.1-beta.1](../../releases/tag/v0.10.1-beta.1).
2. Скачайте `NotifyMark-v0.10.1-beta.1.apk` и `NotifyMark-v0.10.1-beta.1.apk.sha256`.
3. Проверьте SHA-256 APK по checksum-файлу.
4. Разрешите установку APK из выбранного источника, если Android запросит это.
5. Установите APK.
6. При первом запуске разрешите notifications; для точного времени напоминаний разрешите exact alarms, если Android показывает соответствующий special access.
7. Для внешних заметок выберите файл или папку через SAF.

### Проверка checksum

```powershell
$Expected = ((Get-Content ".\NotifyMark-v0.10.1-beta.1.apk.sha256" -Raw).Trim() -split "\s+")[0]
$Actual = (Get-FileHash ".\NotifyMark-v0.10.1-beta.1.apk" -Algorithm SHA256).Hash
$Actual.ToLowerInvariant() -eq $Expected.ToLowerInvariant()
```

Финальный SHA-256 вычисляется из APK, собранного из release tag, проверяется workflow и публикуется одновременно в GitHub Release и `.apk.sha256`. В этот pre-tag документ hash намеренно не копируется из более ранней сборки.

### Обновление с dev/debug-сборок

Поддерживаемый публичный upgrade path пока не заявлен: это первая публичная beta.

Если установленная dev/debug-сборка подписана другим ключом, Android может отклонить установку release APK поверх неё. Не удаляйте старую установку до резервного копирования важных app-owned Markdown-файлов и нужных настроек.

### Разрешения

- **SAF** — пользователь выбирает конкретный файл/папку; NotifyMark сохраняет persistable read/write grant для внешнего источника.
- **Notifications** — разрешение требуется для показа напоминаний на версиях Android, где действует runtime notification permission.
- **Exact alarms** — `SCHEDULE_EXACT_ALARM` нужен для точного времени; Android может требовать отдельный special access.
- **Boot completed** — используется для восстановления расписания после перезагрузки.
- **Vibrate** — используется для вибрации уведомления.

### Откат

Гарантированный rollback между beta и более ранними dev-сборками не заявлен. Удаление приложения может удалить app-owned данные; внешние SAF-файлы остаются у document provider, но доступ к ним после переустановки может потребоваться выдать заново.

## Известные проблемы

### Obsidian Tasks поддерживается частично

- **Не поддерживается:** fenced `tasks` query blocks, query language, group/sort/custom filters.
- **Recurrence:** поддерживается только документированное подмножество; `every ... when done`, `every year` и другие неподдержанные формы не маппятся молча в нативное правило.
- **Dates:** natural-language dates не поддерживаются.
- **Triggers:** `⏳` и `🛫` сами по себе не создают Android reminder.
- **Подробности:** [v0.10.0 compatibility notes](../versions/v0.10.0-obsidian-tasks-plugin-compatibility.md).

### Язык интерфейса\n\n- `Localization: N/A` для `v0.10.1-beta.1`: пользовательский интерфейс приложения доступен на русском языке.\n- Английские README и release notes документируют проект, но не означают наличие английской локализации UI.\n- Полноценная ru/en локализация интерфейса не входит в scope первой публичной beta.\n\n### Android и внешние источники

- точность напоминаний зависит от exact-alarm access и фоновых ограничений Android/производителя;
- SAF-доступ зависит от document provider и может потребовать повторного выбора источника;
- `applicationId` всё ещё содержит прежнее имя проекта.
