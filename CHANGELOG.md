# Changelog

Значимые пользовательские изменения NotifyMark фиксируются здесь кратко; подробные инструкции установки, проверки и ограничения конкретной версии находятся в `docs/releases/`.

## v0.10.1-beta.1 — первая публичная beta

### Добавлено

- публичный beta release pipeline с подписанным APK, security audit, проверкой подписи и SHA-256 checksum;
- частичная совместимость с Obsidian Tasks emoji metadata;
- подготовленные RU/EN release notes и GitHub Issues forms для bug reports и feature requests.

### Изменено

- повторения на карточках отображаются компактнее;
- редактирование длинных заголовков задач стало удобнее;
- README и release-документация приведены к общему формату проекта.

### Ограничения

- Obsidian Tasks поддерживается только частично;
- финальная стабильность `v0.10.1-beta.1` не заявляется до ручного QA tagged APK.

Полные заметки: [docs/releases/v0.10.1-beta.1.md](docs/releases/v0.10.1-beta.1.md).
